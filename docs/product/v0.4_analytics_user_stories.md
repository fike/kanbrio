## 2. User Stories

### Monte Carlo Simulation
- **M-US1**: As a workspace admin, I want to see a histogram of simulated completion dates for the current board state, so I can estimate delivery probability.
- **M-US2**: As a workspace admin, I want to filter the simulation by swimlane or label, so I can forecast specific work streams.
- **M-US3**: As a viewer, I want the simulation to use the last 90 days of throughput by default, so I don't need to configure parameters.
- **M-US4**: As a workspace admin, I want to see P50, P75, P85, P95 percentile markers on the chart, so I can communicate risk levels.

### Cumulative Flow Diagram
- **C-US1**: As a workspace user, I want to see a stacked area chart showing card counts per column over the last 30 days, so I can visualize WIP trends.
- **C-US2**: As a workspace user, I want to hover over the chart to see exact card counts per column at a given date.
- **C-US3**: As a workspace admin, I want to toggle date range presets (7d, 30d, 90d, custom) to zoom into specific periods.

### Cycle Time Scatter Plot
- **S-US1**: As a workspace user, I want to see each completed card plotted as a dot (date on X axis, cycle time on Y axis), with P50/P85/P95 lines.
- **S-US2**: As a workspace user, I want to filter the scatter by swimlane or assignee, so I can compare cycle times across contexts.
- **S-US3**: As a workspace user, I want to highlight outlier cards (above P95) for investigation.

### Flow Efficiency & Aging WIP
- **F-US1**: As a workspace user, I want to see a donut chart showing active time vs wait time as a ratio (percentage), so I can gauge process efficiency.
- **F-US2**: As a workspace user, I want to see a table of the oldest 10 cards in each active column, sorted by idle time descending.
- **F-US3**: As a workspace admin, I want to set an "aging WIP threshold" (default 3 days) to define what counts as stagnant.

## 3. Opportunity Solution Tree (OST)

```
[Opportunity] Improve delivery predictability
├── [Solution] Monte Carlo simulation chart
│   ├── Backend: throughput query + simulation engine
│   └── Frontend: histogram with percentile markers
├── [Solution] Cycle time scatter plot
│   ├── Backend: per-card cycle time aggregation
│   └── Frontend: scatter chart with trend line
│
[Opportunity] Identify flow bottlenecks early
├── [Solution] Cumulative Flow Diagram
│   ├── Backend: daily column snapshots (new table or on-the-fly)
│   └── Frontend: stacked area chart with date range picker
│
[Opportunity] Reduce waste in workflow
├── [Solution] Flow Efficiency donut
│   ├── Backend: active vs wait time from transitions
│   └── Frontend: donut chart + efficiency percentage
├── [Solution] Aging WIP table
│   ├── Backend: cards in active columns with dwell time
│   └── Frontend: sorted table with highlight on stagnant cards
```
